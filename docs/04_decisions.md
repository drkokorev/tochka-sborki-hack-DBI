Известные ограничения MVP:
- Через merge нельзя сбросить параметр («время не важно»): `null` в update означает «не изменилось».
- Правила не понимают имя пациента внутри длинной фразы без «меня зовут» — это закрывает LLM. «Без пятнадцати десять» правила пока не разбирают.
- Направления, кабинеты, участки и готовность анализов стенд не хранит: о направлении спрашиваем пациента, сроки анализов называем по справочнику регламента.
